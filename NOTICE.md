Major PDFCut Studio changes include:

- Windows portable launcher and packaging.
- Bilingual Chinese/English launcher UI.
- Visual crop workflow changes so the selected PDF is passed into the crop window directly.
- One-page crop rectangle reuse across all pages.
- Secure visible-area-only output mode intended to remove cropped-away PDF content while keeping visible text selectable.
- UI naming and product presentation changes under the PDFCut Studio name.
