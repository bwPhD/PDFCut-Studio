# PDFCut Studio Release Notes

## 1.0.0

Initial stable PDFCut Studio portable release.

### Added

- New WPF launcher with clearer typography and bilingual Chinese/English UI.
- Default Chinese interface with runtime language switch.
- Direct handoff from launcher to visual crop window after choosing a PDF.
- Batch crop option to apply one page's crop rectangle to all pages.
- Output logic selector in the visual crop window.
- Secure crop mode designed to remove cropped-away content while preserving selectable text inside the visible crop.
- Fast crop mode for the original boundary-box behavior.
- Portable Windows package with bundled Java runtime.
