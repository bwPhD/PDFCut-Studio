# GitHub Release Template

## Title

PDFCut Studio 1.0.0

## Short Description

Portable visual PDF cropper based on Briss 2.0, with bilingual UI and secure visible-area-only crop output.

## Release Body

PDFCut Studio is a modified GPL-3.0 derivative of Briss 2.0. This release focuses on a smoother Windows workflow, Chinese/English UI, and safer PDF crop output.

### Features

- Chinese interface by default, English available from the launcher.
- Choose a PDF once, then open the visual crop workspace directly.
- Apply one page's crop rectangle to all pages.
- Secure crop mode: keeps text inside the visible crop selectable and removes cropped-away content.
- Fast crop mode: legacy PDF boundary-box crop behavior.
- Portable Windows package with bundled runtime.

### Download

Download and extract `PDFCut-Studio-portable.zip`, then run `PDFCut Studio.vbs`.
